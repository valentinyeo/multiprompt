## Global

| Shortcut | Action |
| --- | --- |
| `Ctrl+Shift+Space` | Start or stop dictation and paste the transcript into the active shell or browser |
| `Enter` while dictation is recording | Stop dictation without submitting shell/browser input; never starts recording |
| `Ctrl+N` | New multiprompt window |
| `Ctrl+K` | Open quick switcher, including while the Chat View composer has focus |
| `Alt+C` | Toggle Chat View for the active terminal; Enter sends, Shift+Enter adds a line |
| `Ctrl+K` -> `Open Chat View` / `Return to Terminal` | Switch between the live transcript and unchanged terminal |
| `Ctrl+K` -> `Stop Agent` | Send Ctrl+C to the active agent from Chat View |
| `Ctrl+K` -> `Move to Group...` | Choose an existing group, create and name a new group, or move the active session to `No group`; Ctrl-selected sessions move together |
| `Ctrl+K` → **Browser Engine** | Switch every pane between the dedicated Edge and dedicated Chrome profiles; future focus, navigation, screenshots, and themes follow the selected engine |
| `Ctrl+K` -> `Reconnect AI Usage Accounts` | Log in only stale Claude telemetry emails, one isolated account at a time, then refresh usage |
| `Ctrl+Shift+G` | Cycle Combined, VPS, and Today's AI telemetry cards |
| `Alt+T` | Create a plain tmux shell in the active workspace's configured or inferred VPS folder; choose the agent yourself |

While Ctrl+K is open, moving the pointer across visible results moves the
highlighted selection. Arrow keys and Enter continue to operate on that same
selection.

| `Ctrl+Shift+T` | Reopen last closed tab |

## Inbox

| Shortcut | Action |
| --- | --- |
| `Alt+I` | Open Inbox; inside Inbox, return to the ALL split |
| `Ctrl+F` or `/` | Live reduction search across session name, workspace, path, agent, and preview text |
| `j` / `k` or `Alt+J` / `Alt+K` | Move down / up the current Inbox split |
| `e` or `Alt+E` | Move the selected row to Waiting across restarts; a blue dot reveals it, opening that blue-dot row restores it, and spinner activity alone keeps it waiting |
| `z` or `Alt+Z` | Undo the most recent move to Waiting and restore its previous read/unread state |
| `Alt+H` | Remind Me for the selected Inbox row; its tmux session keeps running (`Ctrl+Shift+H` remains an alias) |
| `Alt+X` | Archive selected tmux session, or close a non-tmux tab (press twice) |
| `q` / `Esc` | Close Inbox |

Waiting lasts until a blue dot, `Alt+Z`, manual mark-unread, or explicit reactivation from **All Sessions** (`Ctrl+K` → **Show All Sessions**). Undo remembers one successful move at a time; destructive `Alt+X` archive actions are not undoable. Opening a waiting row from All Sessions restores it to the Inbox and workspace sidebar. Archived sessions are separate stopped records and restore individually.

After opening a session, returning to Inbox restores focus to that same session by identity even if activity changed its sorted position.
The Windows title/taskbar label shows `Inbox` while this view is open, then follows the workspace of every session opened with Enter, `Alt+J/K`, or `Alt+E`.
Sessions opened from Inbox always land with keyboard focus in the shell, never the docked browser pane.

## Browser Pane

| Shortcut | Action |
| --- | --- |
| `Alt+A` | Open or reconnect browser pane |
| `Alt+W` | Open a URL from the shell buffer in a fresh pane tab and focus it |
| `Alt+Q` | Switch keyboard focus between shell and browser pane, including while the selected browser's address bar is focused |

## Focus Rule

Browser-focused keyboard shortcuts should usually pass through to the selected Edge or Chrome pane. Shell-focused shortcuts may be handled by multiprompt. tmux prefix sequences must remain tmux-owned.

Do not add `Ctrl+Alt` shortcuts. On the user keyboard, `Ctrl+Alt` is AltGr.
