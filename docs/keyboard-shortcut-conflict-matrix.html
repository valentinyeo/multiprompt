Recommended Namespace Rules

  • Do not use Ctrl+Alt combinations. On this machine Ctrl+Alt is AltGr, and the project notes explicitly say not to use Ctrl+Alt shortcuts.
  • Do not add more Ctrl+Shift+letter commands as universal ZigShell commands. Edge and DevTools already occupy many of them, including Ctrl+Shift+I, J, C, M, K, L, O, R, T, U, V, B, E, and F.
  • Use focus-scoped routing. Browser-focused keys should usually pass to Edge; shell-focused keys may remain ZigShell shortcuts; tmux prefix sequences should be left alone.
  • Inbox recommendation: add Ctrl+Shift+. as the primary Inbox shortcut everywhere, including browser focus. Keep Alt+I as a browser-focus escape hatch, and keep Ctrl+Shift+I as a legacy shell-only alias if desired.

Why Ctrl+Shift+Alt+I Is Not Recommended

It looks unique, but it uses Ctrl+Alt. On US-International layouts Ctrl+Alt behaves like AltGr, which conflicts with text entry and was explicitly called out in the repo instructions as a shortcut family to avoid.
