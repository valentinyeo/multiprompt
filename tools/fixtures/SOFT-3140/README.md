# Missing sidebar chat

`yeo-ux-missing.json` reproduces the reported shape: a chat belongs to Yeo UX and is in the desktop layout, but has no sidebar row and is not Waiting. It is a synthetic, sanitized report, not captured desktop telemetry. The supplied screenshot shows an empty Waiting cluster: https://screencast2.com/VupCJ.png.

The regression suite also varies this report for a visible pinned chat, unread filtering, another workspace, collapsed groups and sections, snoozed workspaces, deliberate hiding, Waiting, missing layout membership, offline desktops and older desktop reports.
